## [1.6.0] — unreleased

### Added
- **The reach of a radial density channel** (`descriptors/density_reach.h`): `kDensityReachFloor` (1e-6), the one value below which a radial function at a neighbour distance, or the density of an atom, counts as zero; `neighbour_range(data, rcut)`, the neighbour distances a density with cutoff `rcut` sums over; `gaussian_reach_width(d)`, the width above which a Gaussian is below that floor at distance `d` from its centre; `radial_reach_check(data, seed, kind)`, the `CGRIDMB` check of the densities (below); and `gaussian_centre_suggestion` and `gaussian_width_suggestion`, the `CGRIDMB` and `SGRIDMB` suggestions of the Gaussian densities, which read the seed (below).
- **`SeedView(context, first_entries)` and `SeedView::entry_number(key, i)`** (`param_meta.h`): a view of the context of one descriptor of a joined `TYPE2B` or `TYPEMB` line (`D_mJoin::parse_context`), which holds its share of each list key, with the number of values of each key that come before its own; `entry_number` gives the 1-based number of a value in the whole key, as an `OPTIM` line names it, and `radial_reach_check` names a channel by it (`CGRIDMB(3) = 30`, the second channel of a `DM_Blip` joined after a `DM_EAD` of one channel). A view of a whole configuration numbers from 1.
- **`BoundSuggestion`** (`param_meta.h`): what a `BoundSuggester` returns, a range (`first`, `second`, as the pair it extends, which converts to it) with its rationale (the form it assumes and the data it comes from), `fixed` for a range that is not derived from the data (`fixed_range()`), and `none` for an entry without an `OPTIM` line (`no_row()`).
- **`eam_lattice::reach_distance(lattice, a0, reach_smin)` and `require_crystal_on_grid(lattice, a0, reach_smin, dr, rcut)`** (`eam_lattice.h`): the nearest-neighbour distance of the crystal compressed to a/a0 = `reach_smin`, which `EAMRefit::analyze_reachability` takes as `r_reach`, and the crystal gate of `tadah refit` (MLIP's `RefitEngine::run()`): `require_crystal`'s rules (a known lattice, a0 > 0); then a crystal whose nearest neighbours at a0 are at or beyond the table's cutoff `rcut` is refused (LAMMPS, `pair_style eam/alloy`, counts a pair only below `rcut`, so in LAMMPS the crystal has no interaction; tadah's `neighbour_distances`, D2_EAM and DM_EAM keep a pair at exactly `rcut`: `tadah refit: the lattice constant of the EAM header, a0 = 361 A, puts the nearest neighbours of the fcc crystal 255.26554800834364 A apart, at or beyond the table's cutoff, rcut = 5 A, and LAMMPS (pair_style eam/alloy) counts a pair only below rcut: the crystal has no interaction in LAMMPS. Edit the element line of the setfl file (...): set the equilibrium lattice constant, in Angstrom (a value in picometres is 100 times the value in Angstrom).`), and so is one whose nearest neighbours at a/a0 = `REFIT_REACH_SMIN` are less than the step `dr` of the table's radial grid apart, naming a0, the lattice, the distance, `REFIT_REACH_SMIN` and `dr` (`tadah refit: the lattice constant of the EAM header, a0 = 1e-323 A, puts the nearest neighbours of the fcc crystal 0 A apart at the strongest compression the refit tests (a/a0 = REFIT_REACH_SMIN 0.1), less than the step of the table's radial grid, dr = 0.0125313 A: the table describes no pair distance of that crystal. Edit the element line of the setfl file (...): set the equilibrium lattice constant, in Angstrom.`), so `dr` <= `r_reach` < `rcut` for every table it passes. Tests: `test_eam_lattice.cpp`.
- **`Function_Base::mparams()`** (`MParamSlot`: name, integer, positive): the `MPARAMS` values a basis function or kernel reads when it is built, in order. `Kern_RBF`: `sigma` (positive); `Kern_Polynomial`: `d` (an integer, positive), `gamma`, `c`; `Kern_Sigmoid`: `gamma`, `c`; every other function none (the default). Tadah.HPO checks `OPTIM MPARAMS` against it at startup. Test: `test_function_mparams.cpp`.
- **`shared_setfl(path)`** (`eam_setfl_io.h`): the setfl file read and splined once for every caller of the process that reads the same file (the path as given, in the working directory it names) while its bytes are unchanged; a call reads the file and parses it again when its contents changed (a table already handed out is not changed). `EAMSetflIO::read_setfl_text(text, path)` parses the contents of a setfl file. Test: `test_eam_setfl_cache.cpp`.
- **`log_warning_once(key, message)`** and `warning_logged_once(key)` (`descriptors/warn_once.h`): a Logger WARNING at most once per process for a key, used by the descriptor warnings below; a call while the Logger hides WARNINGs does not use up the key.
- **`D_Base::cutoff_fixed_by(i)`**: what fixes value i of a descriptor's cutoff key (`RCUT2B`, `RCUTMB`), as a clause for a message, or "" for a value the descriptor takes as a free parameter (the default). D2_EAM and DM_EAM answer the cutoff of their setfl file for every value (`setfl_cutoff_clause`: `D2_EAM takes the cutoff 5.58190742024 of its setfl file 'Ta.eam.alloy' (SETFL)`; "" when built with `INIT2B`/`INITMB` false); D2_mJoin and DM_mJoin answer with the joined descriptor that takes value i. Tadah.HPO refuses `OPTIM RCUT2B`/`RCUTMB` on such a value at startup. Test: `test_eam_descriptors.cpp`.

- **`zero_rows(Phi, rows)` and `zero_rows(Phi, rows, factors)`** (`zero_rows.h`): which data rows of a design matrix are zero in every column, a value of at most `kZeroRowTolerance` (1e-10) times the largest magnitude of its column counting as zero, so that the rounding of sums that cancel (the force rows of an atom at a centre of symmetry, about 1e-16) does not decide whether a row counts. With the row factors of a fit the largest magnitudes are taken over the rows of factor above 0, and a row of factor 0 or less is zero: a row the fit leaves out (priority 0) does not decide whether another row is zero. LinearRegressor's count of non-zero data rows and Tadah.MLIP's count of the observations of a fit (with the factors) take it from there. Tests: `test_zero_rows.cpp`, `test_linear_regressor_messages.cpp` (`LinearRegressor: OALGO 2 and 4 count a data row of rounding residues as zero`).

Tests: `test_oalgo3_fit.cpp`, `test_oalgo3_solve.cpp`, `test_rank_threshold.cpp`.

### Changed
- **The `CGRIDMB` check of a many-body density judges a channel by its reach, not by its centre** (`DM_mBlipEnv`, `DM_EAD`, the `DM_mEAD` and `DM_Poly` families, `DM_Blip`; `radial_reach_check`): a Gaussian channel `exp(-SGRIDMB (r - CGRIDMB)^2)` fails when it is below 1e-6 at every neighbour distance of the data within `RCUTMB` (from the smallest r_min of the element pairs to the smaller of their r_max and `RCUTMB`), a blip channel when its support, |r - `CGRIDMB`| < 2/`SGRIDMB`, holds none of them; a cutoff below every neighbour distance fails too. The message names the channel, its width, the form and the distances (`CGRIDMB(1) = 30 with SGRIDMB(1) = 0.2: the Gaussian exp(-SGRIDMB (r - CGRIDMB)^2) is below 1e-6 at every neighbour distance within RCUTMB = 5.6 (2.25 to 5.6 Å), ...`). Tadah! 1.5.0 failed every centre outside [r_min, r_max] whatever its width (`CGRIDMB=0.000000 is outside the dataset's r_ij range ... — ρ will be ~0 for every atom`): the seed of a Gaussian centred at the origin, whose width reaches the first neighbours, failed `tadah analysis check_bounds` at every corner and was refused by `AUDIT error`. The ρ-collapse checks of `DM_mBlipEnv` and `DM_Blip` compare with the same 1e-6.
- **The suggested `CGRIDMB` and `SGRIDMB` ranges of a Gaussian density read the seed, entry by entry** (`DM_mBlipEnv`, `DM_EAD`, the `DM_mEAD` families, the Gaussian `DM_Poly` families): a centre at the origin gets no `CGRIDMB` range, and its width the range over which `exp(-SGRIDMB r^2)` drops by a factor of 0.9 to 1/20 from the first neighbour shell to the second, ln(1/0.9)/(r2^2 - r1^2) to ln(20)/(r2^2 - r1^2), at most the width at which it is 1e-6 at r_min (about 0.04 to 1.1 Å^-2 for bcc Ta). Any other centre c gets c ± the FWHM of the neighbour shell nearest to it (the peak of the distances nearest to c; 0.2 times its distance for a peak without a FWHM), its low end not below r_min and its high end not above the distances within `RCUTMB` unless c lies outside them, so that the range holds c, and its width 0.25/w^2 to 9/w^2 with w that FWHM. Without a seed centre, the first peak ± its FWHM from r_min. Each rationale names the form it assumes, the seed's centre and the shell. ## [1.3.0-beta.1] — 2026-05-20

The largest module-level surface change of this release: a new family of rotationally invariant power-spectrum descriptors (`DM_Poly` and friends), new `F_Blip` / `DM_mBlip` / `DM_mBlipEnv` embedding-function descriptors, in-place HPO `reinit()` plumbing, and a corrected `Cut_PT` normalisation.

### Added
- `DM_Poly<ChannelFn>` — rotationally invariant power-spectrum descriptor with blip radial basis. Registered variants:
  - `DM_PS_SQ`, `DM_PS_SQRT`, `DM_PS_RLR`, `DM_PS_Blip` (channel = power spectrum).
  - `DM_OW_*` and `DM_GOW_*` variants (`AggMode` template parameter — orbital-wise / general orbital-wise aggregation).
  - `DM_GPS_SQ`, `DM_GPS_SQRT`, `DM_GPS_RLR`, `DM_GPS_Blip` (`RadialBasis` template parameter — `GaussianRadial` instead of `BlipRadial`).

- `F_Blip` embedding function and `DM_mBlip` descriptor.
- `DM_mBlipEnv` — inverse-envelope variant of `DM_mBlip` that wraps the `F_Blip` embedding in a `Cut_SinInv` envelope (controlled by the new `RCUTENV` blueprint key).
- `descriptor::reinit()` and `DC_Selector::reinit()` — in-place parameter updates for HPO.
- Single-ρ support and generalisation of the `F_` (embedding) function family.
- DM_Poly test suite.
- Doxygen / LaTeX documentation for basis functions and `DM_Blip`.
- `TADAH_ENABLE_ASAN` CMake option.

- `DM_mJoin` corrections and `drfidx` added.

### Performance

### Internal

- Substantive README rewrite (Session B).
